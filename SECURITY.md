# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SentinelGraph, please report it privately to the repository owner or project maintainers.

Please include:

- A clear description of the issue.
- Steps to reproduce, if safe to share.
- Affected files, commands, or configuration.
- Any suggested mitigation.

Do not open a public issue for sensitive security reports.

## Scope

In scope:

- Vulnerabilities in SentinelGraph code, configuration, reports, or dashboard generation.
- Dependency vulnerabilities that directly affect SentinelGraph.
- Unsafe behavior in DataHub reads, writes, publishing, or target scoping.

Out of scope:

- Vulnerabilities in third-party services not bundled with SentinelGraph.
- Issues requiring access to systems where you do not have authorization.

## Responsible Use

SentinelGraph is intended for authorized security analysis in data environments. Use it only where you have permission to inspect metadata, assess risk, and publish findings.
