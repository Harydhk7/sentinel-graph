# AI-Assisted Contributions

AI tools may be used to draft or review SentinelGraph changes, but the contributor remains responsible for every line submitted.

Before opening a PR:

- Read the diff in full.
- Remove copied upstream metadata, maintainer handles, sponsor links, and unrelated project references.
- Run the relevant tests or document why a check could not be run.
- Keep generated text concise and specific to SentinelGraph.
- Do not add broad security claims that are not backed by tests, examples, or documentation.
- Do not weaken authorization, publishing, or DataHub target-scope checks without explaining the security impact.

AI assistance is fine; unreviewed output is not.
